MaxiMeter Shader Documentation

MaxiMeter's 3D viewport is powered by Three.js r169 running inside an Edge WebView2 window. Shaders are written in GLSL ES 3.0 and compiled as Three.js ShaderMaterial. Both the Vertex and Fragment shader are edited live in Monaco Editor and applied by pressing ⚙ Compile All.

NDCNormalised device coordinates: x,y in [-1,1], z in [0,1].
Window / Fragment spacegl_FragCoord.xy in physical pixels from bottom-left.

Audio Data

uAudioData is a 128-element float array fed from the C++ audio engine at ~30 Hz.

Index rangeDataValue rangeNotes
0 63Waveform (time-domain, mono)-1.0 .. 1.0Most recent 64 samples. Index 0 = oldest, 63 = newest.
64 127Spectrum magnitude (FFT)0.0 .. 1.0FFT bins. 64 = sub-bass, 127 = high. Pre-normalised.

Accessing audio in GLSL

Array indexing rule: GLSL ES 3.0 requires array indices to be compile-time constants or loop variables with constant bounds. Use min(int(...), 127) to guard dynamic indices.
// Constant index
float bass = uAudioData[64];

// Safe loop
float energy = 0.0;
for (int i = 0; i < 64; i++) energy += abs(uAudioData[i]);
energy /= 64.0;

// Dynamic index (guard with min)
int idx = min(int(vUv.x * 64.0), 63);
float wave = uAudioData[idx];        // waveform
float spec = uAudioData[64 + idx];   // spectrum

Frequency band helpers

float subBass() { float s=0.; for(int i=64;i<68;i++)  s+=uAudioData[i]; return s/4.; }
float bass()    { float s=0.; for(int i=68;i<76;i++)  s+=uAudioData[i]; return s/8.; }
float mid()     { float s=0.; for(int i=76;i<96;i++)  s+=uAudioData[i]; return s/20.; }
float treble()  { float s=0.; for(int i=96;i<128;i++) s+=uAudioData[i]; return s/32.; }
float rms()     { float s=0.; for(int i=0;i<64;i++) s+=uAudioData[i]*uAudioData[i]; return sqrt(s/64.); }

Vertex Shader

Runs once per vertex. Must compute gl_Position. Passes data to fragment via varyings declared with out.

Minimal template

precision highp float;

// Three.js built-in attributes (auto-declared, do NOT redeclare):
//   in vec3 position;   in vec3 normal;   in vec2 uv;

out vec2 vUv;
out vec3 vNormal;

void main() {
    vUv      = uv;
    vNormal  = normalize(normalMatrix * normal);
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}

ShadertoyQuad template (fullscreen effect)

void main() {
    // Emit NDC directly  camera matrices not used
    gl_Position = vec4(position.xy, 0.0, 1.0);
}

World-space position template

out vec3 vWorldPos;
out vec3 vViewNormal;

void main() {
    vec4 worldPos = modelMatrix * vec4(position, 1.0);
    vWorldPos   = worldPos.xyz;
    vViewNormal = normalize(normalMatrix * normal);
    gl_Position = projectionMatrix * viewMatrix * worldPos;
}

Fragment Shader

Runs once per rasterised pixel. Must write gl_FragColor.

MaxiMeter automatically prepends out highp vec4 pc_fragColor; #define gl_FragColor pc_fragColor use gl_FragColor freely as in GLSL 1.0 / Shadertoy.

Minimal template

precision highp float;

in vec2 vUv;

void main() {
    gl_FragColor = vec4(vUv, 0.5 + 0.5 * sin(uTime), 1.0);
}

Built-in fragment inputs

VariableTypeDescription
gl_FragCoordvec4.xy = pixel coords from bottom-left in physical pixels. .z = depth [0..1]. .w = 1/clipW.
gl_FrontFacingbooltrue if fragment is front-facing.
gl_PointCoordvec20..1 within a rendered point sprite. Only valid for THREE.Points.

UV from fragment coordinates (Shadertoy style)

// UV 0..1 from bottom-left
vec2 uv = gl_FragCoord.xy / uResolution;

// Centred UV -1..1, aspect-corrected (standard Shadertoy style)
vec2 uv = (gl_FragCoord.xy * 2.0 - uResolution) / uResolution.y;

Varyings

Varyings carry interpolated data from vertex to fragment. An out T name in vertex must have a matching in T name in fragment same name, same type, same precision qualifier.

// Vertex shader
out vec2  vUv;
out vec3  vNormal;
out vec3  vWorldPos;
out float vHeight;

// Fragment shader
in vec2  vUv;       // must match exactly
in vec3  vNormal;
in vec3  vWorldPos;
in float vHeight;
Error: FRAGMENT varying X does not match any VERTEX varying a name in in (fragment) has no corresponding out (vertex). Check spelling and type exactly.
Precision qualifiers must match too. If vertex declares out highp vec3 vPos, fragment must also use in highp vec3 vPos or omit precision qualifiers on both and let the precision statement apply.

Waveform3D example

// Vertex
in float aIndex;
out float vAmp;

void main() {
    int   idx = int(aIndex);
    float amp = uAudioData[idx];   // waveform -1..1
    vec3  p   = position;
    p.y += amp * 3.0;
    vAmp = amp;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(p, 1.0);
}

// Fragment
in float vAmp;

void main() {
    float t   = abs(vAmp);
    vec3  col = mix(vec3(0.0,0.4,1.0), vec3(1.0,0.1,0.0), t);
    gl_FragColor = vec4(col, 1.0);
}

Particles3D soft circular sprite

// Vertex
in float aPhase;
out float vBright;

void main() {
    float rmsVal = 0.0;
    for (int i = 0; i < 32; i++) rmsVal += uAudioData[i] * uAudioData[i];
    rmsVal = sqrt(rmsVal / 32.0);
    vec3 p  = position;
    p.y    += sin(uTime * 1.2 + aPhase * 5.0) * (0.5 + rmsVal * 3.0);
    gl_PointSize = 4.0 + rmsVal * 20.0;
    vBright = rmsVal;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(p, 1.0);
}

// Fragment
in float vBright;

void main() {
    vec2  d     = gl_PointCoord - vec2(0.5);
    float r     = length(d);
    float alpha = 1.0 - smoothstep(0.3, 0.5, r);
    if (alpha < 0.01) discard;
    vec3  col   = mix(vec3(0.1,0.5,1.0), vec3(1.0,0.3,0.0), vBright * 4.0);
    gl_FragColor = vec4(col, alpha * 0.9);
}

Operators & Swizzling

Arithmetic

All arithmetic operators work component-wise on vectors. Scalar-vector ops broadcast the scalar:

vec3 a = vec3(1.0, 2.0, 3.0);
vec3 b = a * 2.0;            // (2, 4, 6)
vec3 c = a + vec3(1,0,0);    // (2, 2, 3)
vec3 d = a * a;              // (1, 4, 9)  component-wise, NOT dot product!
vec3 e = a / vec3(2.0);      // (0.5, 1.0, 1.5)

Swizzling

Access and rearrange vector components using sets xyzw (geometry) or rgba (colour) or stpq (texture):

vec4 v = vec4(1.0, 2.0, 3.0, 4.0);
vec2 a = v.xy;      // (1, 2)
vec3 b = v.zyx;     // (3, 2, 1)  reorder
vec3 c = v.rrr;     // (1, 1, 1)  repeat
vec4 d = v.wzyx;    // (4, 3, 2, 1)
v.xy   = vec2(9.0, 8.0);  // write via swizzle
vec3 e = v.rgb;     // same as v.xyz

Matrix multiplication

// matrix x column-vector (standard transform)
vec4 clip = projectionMatrix * modelViewMatrix * vec4(position, 1.0);

// matrix x matrix
mat4 mvp = projectionMatrix * viewMatrix * modelMatrix;

// component-wise multiply (NOT the same as mat*mat):
mat2 cw = matrixCompMult(a, b);

// matrix x row-vector (transpose semantics)
vec3 v2 = vec3(1,0,0) * mat3(modelMatrix);

Ternary operator

float x = (t > 0.5) ? 1.0 : 0.0;
// Branchless equivalent (preferred on GPU):
float x = step(0.5, t);
// Smooth branchless:
float x = smoothstep(0.45, 0.55, t);

Control Flow

Conditionals

if (condition) { ... } else if (other) { ... } else { ... }
On GPU, both branches of an if are often evaluated. Use mix() or step() for branchless equivalents in performance-critical paths.

Loops

for (int i = 0; i < 64; i++) { ... }
while (condition) { ... }
do { ... } while (condition);
break;    // exit loop early
continue; // skip to next iteration
Loop bounds must be deterministic at compile time. Avoid dynamic iteration counts. Very large loops (>1024 iterations) can cause GPU timeouts. Raymarching: use 64128 steps maximum.

discard

// Fragment shader only  kills this fragment (no output written, no depth write)
if (alpha < 0.01) discard;
discard prevents early-Z optimisation and is expensive in overdraw situations. Use sparingly.

Function definitions

// In GLSL all functions must be declared before use (or prototype first)
float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5*(b-a)/k, 0.0, 1.0);
    return mix(b, a, h) - k*h*(1.0-h);
}

// Parameter qualifiers
void modify(in float input, out float output, inout vec3 both) {
    output = input * 2.0;
    both  *= 0.5;
}

Replacing iChannel0 with procedural noise

// Value noise (replaces texture(iChannel0, uv).r)
float hash21(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}
float vnoise(vec2 p) {
    vec2 i = floor(p), f = fract(p);
    vec2 u = f*f*(3.0 - 2.0*f);                     // cubic Hermite
    return mix(mix(hash21(i),         hash21(i+vec2(1,0)), u.x),
               mix(hash21(i+vec2(0,1)),hash21(i+vec2(1,1)), u.x), u.y);
}

// Fractional Brownian Motion (replaces multi-octave texture noise)
float fbm(vec2 p) {
    float v = 0.0, a = 0.5;
    for (int i = 0; i < 5; i++) { v += a*vnoise(p); p *= 2.0; a *= 0.5; }
    return v;
}

// Usage where Shadertoy had: texture(iChannel0, uv * scale).r
float val = vnoise(uv * 4.0 + uTime * 0.1);

float rms = 0.0;
for (int i = 0; i < 64; i++) rms += uAudioData[i] * uAudioData[i];

Math Patterns

Rotation matrices

mat2 rot2(float a) {
    float c = cos(a), s = sin(a);
    return mat2(c, -s, s, c);
}
vec3 rotX(vec3 p, float a) { vec2 r = rot2(a)*p.yz; return vec3(p.x, r); }
vec3 rotY(vec3 p, float a) { vec2 r = rot2(a)*p.xz; return vec3(r.x, p.y, r.y); }
vec3 rotZ(vec3 p, float a) { vec2 r = rot2(a)*p.xy; return vec3(r, p.z); }

2D SDF primitives

float sdCircle(vec2 p, float r)          { return length(p) - r; }
float sdBox(vec2 p, vec2 b) {
    vec2 d = abs(p) - b;
    return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}
float sdSegment(vec2 p, vec2 a, vec2 b) {
    vec2 pa = p-a, ba = b-a;
    float h = clamp(dot(pa,ba)/dot(ba,ba), 0.0, 1.0);
    return length(pa - ba*h);
}
float sdHexagon(vec2 p, float r) {
    const vec3 k = vec3(-0.866,0.5,0.577);
    p = abs(p);
    p -= 2.0*min(dot(k.xy,p),0.0)*k.xy;
    p -= vec2(clamp(p.x,-k.z*r,k.z*r), r);
    return length(p)*sign(p.y);
}

// Anti-aliased fill from SDF
float sdFill(float d, float aa) { return 1.0 - smoothstep(-aa, aa, d); }

3D SDF primitives

float sdSphere(vec3 p, float r)         { return length(p) - r; }
float sdBox3(vec3 p, vec3 b) {
    vec3 d = abs(p) - b;
    return length(max(d,0.0)) + min(max(d.x,max(d.y,d.z)),0.0);
}
float sdTorus(vec3 p, vec2 t) {
    return length(vec2(length(p.xz)-t.x, p.y)) - t.y;
}
float sdCylinder(vec3 p, float r, float h) {
    vec2 d = abs(vec2(length(p.xz),p.y)) - vec2(r,h);
    return min(max(d.x,d.y),0.0) + length(max(d,0.0));
}

// Smooth minimum (organic blending)
float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5*(b-a)/k, 0.0, 1.0);
    return mix(b, a, h) - k*h*(1.0-h);
}

Normal from SDF (central differences)

vec3 calcNormal(vec3 p) {
    vec2 e = vec2(0.001, 0.0);
    return normalize(vec3(
        map(p+e.xyy) - map(p-e.xyy),
        map(p+e.yxy) - map(p-e.yxy),
        map(p+e.yyx) - map(p-e.yyx)
    ));
}

Raymarching scaffold

float map(vec3 p) {
    return sdSphere(p, 1.0 + 0.2*sin(uTime));
}

void main() {
    vec2  uv = (gl_FragCoord.xy*2.0 - uResolution) / uResolution.y;
    vec3  ro = vec3(0.0, 0.0, 3.0);
    vec3  rd = normalize(vec3(uv, -1.5));

    float t   = 0.0;
    bool  hit = false;
    for (int i = 0; i < 96; i++) {
        vec3  p = ro + rd*t;
        float d = map(p);
        if (d < 0.001) { hit = true; break; }
        if (t > 20.0)  break;
        t += d;
    }

    vec3 col = vec3(0.0);
    if (hit) {
        vec3  p = ro + rd*t;
        vec3  n = calcNormal(p);
        vec3  L = normalize(vec3(1.0, 2.0, 1.5));
        col = vec3(0.4, 0.7, 1.0) * (0.1 + 0.9*max(dot(n,L), 0.0));
    }
    gl_FragColor = vec4(col, 1.0);
}

Value noise and fBm

float hash21(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}
float vnoise(vec2 p) {
    vec2 i = floor(p), f = fract(p);
    vec2 u = f*f*(3.0 - 2.0*f);
    return mix(mix(hash21(i),          hash21(i+vec2(1,0)), u.x),
               mix(hash21(i+vec2(0,1)), hash21(i+vec2(1,1)), u.x), u.y);
}
float fbm(vec2 p) {
    float v = 0.0, a = 0.5;
    for (int i = 0; i < 6; i++) { v += a*vnoise(p); p *= 2.0; a *= 0.5; }
    return v;
}

Gradient noise (smoother than value noise)

vec2 hash22(vec2 p) {
    p = vec2(dot(p,vec2(127.1,311.7)), dot(p,vec2(269.5,183.3)));
    return fract(sin(p)*43758.5453) * 2.0 - 1.0;
}
float gnoise(vec2 p) {
    vec2 i = floor(p), f = fract(p);
    vec2 u = f*f*(3.0-2.0*f);
    float a = dot(hash22(i),         f);
    float b = dot(hash22(i+vec2(1,0)), f-vec2(1,0));
    float c = dot(hash22(i+vec2(0,1)), f-vec2(0,1));
    float d = dot(hash22(i+vec2(1,1)), f-vec2(1,1));
    return mix(mix(a,b,u.x), mix(c,d,u.x), u.y);
}

// HSV to RGB
vec3 hsv2rgb(vec3 c) {
    vec4 K = vec4(1.0, 2.0/3.0, 1.0/3.0, 3.0);
    vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
    return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
}

// Gamma correction (linear to sRGB)

// Exposure tone-map

    c *= exposure;

Performance Tips

  • Raymarching: keep to 64128 steps. Shadertoy originals often use 2561024 steps, which may GPU-timeout in WebView2.
  • Use break on hit don't march all steps after intersection.
  • Prefer branchless: mix(), step(), smoothstep() over if in hot per-pixel loops.
  • Avoid pow() with dynamic base + large exponent. Use exp(exponent * log(base)) for fractional powers.
  • Cache normalize() result in a variable if used multiple times it computes a sqrt.
  • Limit fBm octaves to 46. Each octave doubles noise cost.
  • For Particles3D: keep gl_PointSize <= 64 px for acceptable fill-rate on most GPUs.
  • Pack multiple small varyings into one vec4 to reduce interpolator count.
  • Avoid texture lookups in vertex shaders on WebGL2 if possible prefer precomputed attributes.
  • Use mediump only for colour outputs after profiling avoid for positions, time, and index math.
  • Discard fragments only when necessary: discard disables early-Z and hurts overdraw performance.
  • For spectrum loops: read only as many bins as needed. Full 64-bin loop runs on every fragment.
